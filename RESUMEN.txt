┌─ 🎨 CÓMO PROBAR UN ENDPOINT EN SWAGGER ────────────────────────────────────┐
│                                                                              │
│  1. Abre Swagger UI en http://localhost:8080/swagger-ui.html              │
│  2. Expande "Gestión de Usuarios"                                          │
│  3. Selecciona el endpoint que deseas probar                               │
│  4. Haz clic en "Try it out"                                               │
│  5. Completa los parámetros con datos de prueba                            │
│  6. Haz clic en "Execute"                                                  │
│  7. ¡Ve la respuesta en tiempo real!                                       │
│                                                                              │
│  Ejemplo: Para registrar un usuario                                         │
│     • Endpoint: POST /api/usuarios/registro                                │
│     • Body: {"nombreUsuario": "test", "email": "...", ...}               │
│     • Response: 201 Created con datos del usuario                          │
